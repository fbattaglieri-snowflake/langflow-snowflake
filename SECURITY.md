# Security policy

This is an unofficial community project without a security support SLA.
Only the latest reviewed commit is maintained. Dependency scan status must be
checked before deployment; no production suitability is promised.

Use GitHub's private vulnerability reporting if enabled. Otherwise contact a
maintainer privately using their public GitHub profile. Do not publish a secret
or working exploit against somebody else's account in a public issue. If a
credential is exposed, revoke/rotate it through its issuer and review access
history; deleting a Git commit alone does not revoke credentials.
